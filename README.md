ShoppingCartSystem 🛒
Overview
ShoppingCartSystem is a simplified online shopping system developed as an Object-Oriented Programming project in Java.
Project Description
The system simulates a basic online shopping flow where customers can view products, add products to a shopping cart, and create orders through checkout.
Main Components
Store: Manages products and customers.
Customer: Stores customer information and owns a shopping cart and orders.
ShoppingCart: Manages selected products and calculates the total.
Product: Abstract class representing shared product properties.
PhysicalProduct: Extends Product with additional product information.
Order: Represents completed purchases.
Borrowable: Interface for availability-related behavior.
ProductNotFoundException: Handles cases where a product cannot be found.
